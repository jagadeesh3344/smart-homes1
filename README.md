# 🏛️ Aetheria Smart Home & Automation Ecosystem (Major Project)

An enterprise 3-tier distributed smart home automation ecosystem featuring a **Customer Storefront Web App**, **IoT Admin Management Console**, and a **Unified Real-time Backend Server** with Server-Sent Events (SSE), Razorpay payment simulation, and automatic tax invoice generation.

---

## 🚀 Quick Start (3 Steps)

1. **Install Dependencies (Only needed once)**:
   Double-click `install-dependencies.bat`
2. **Run on Any Network / Worldwide Access**:
   Double-click `start-with-public-internet.bat`
   *(Works on ANY Wi-Fi, 4G, 5G, or mobile hotspot without firewall issues)*
3. **Or Run Locally on Same Wi-Fi**:
   Double-click `start-all.bat`
